01
STUDIO CLASSIC

经典影棚肖像伦勃朗光 · 专业头像 · timeless 质感

最正统的棚拍人像：单灯或双灯布光、纯色背景、突出人物本身。核心是「伦勃朗光」——主灯位于人物斜上方 45°，在暗侧脸颊留下一个倒三角形光斑，立体感与情绪兼备。

光
主灯 45° 高位 + 柔光箱

柔光箱越大人造光越柔；主灯高于眼睛往下打，颧骨下形成三角光即伦勃朗光位。可加一块反光板或弱光填充暗部，控制光比 1:2 ~ 1:4。

背
纯色无缝背景纸

人物离背景 1.5m 以上，避免投影落在背景上；灰背景最百搭，白加亮、压暗即可切换调性。

姿
先转肩、再转脸

身体侧 30–45°、脸转回镜头，显瘦且立体；下巴微向前向下，收紧下颌线。

85mm f/2ISO 1001/125s（同步快门）对焦：近侧眼
完整拍摄方案 · 器材 / 场景 / 灯光 / 人物 / 参数 / 后期
器材全画幅机身（5D4/A7M4）+ 85mm f/1.4–2（或 80–105mm 定焦、70–200 f/2.8）；一盏 100–150cm 八角柔光箱作主灯，一条条形灯束光筒做发丝光，黑白反光板各一，灰卡校色。
场景层高 ≥2.5m 的影棚，2.72m 宽深灰/炭灰无缝纸；机位距人物 3–4m，人物离背景 1.5–2m，让阴影退到画面外。
灯光主灯八角箱放人物前侧上方 45°、灯心略高于头顶对准鼻尖，让阴影侧脸颊出现鼻下三角形亮区（底朝下、不越过眼线）；对面 1/8 功率条形灯或白色反光板填充，光比约 4:1；发丝光后上方 45° 条灯打头顶发缘；可选背景灯出灰渐变。先用造型光确认三角光位置再试拍。
人物与引导女：米白/大地色上衣+西装外套；男：深色西装。妆全哑光防油光。引导：先正面站定→肩部向后转约 30°→脸转回对光方向、视线越过镜头；下巴前伸微收收紧下颌线；确认眼神光落在瞳孔 10–11 点方向。
相机参数ISO 100｜f/4–5.6（眼睛锐利、皮肤微微柔化）｜快门 1/160 同步速度｜点测光面部，闪光灯输出再收 1/3｜白平衡 5600K 闪光。
后期处理Capture One/LR 校肤色；加深加深眼部与眼神光；中性灰磨皮保留质感；曲线压背景成中心亮边缘暗的晕影；锐化只加眼睛。
02
HIGH-KEY

高调明亮风格纯净 · 通透 · 商业美妆感

画面整体偏亮、阴影极少、背景纯白，传递干净、青春、愉悦的情绪。常用于母婴、美妆、婚纱和日系写真。关键是让背景比主体更亮（过曝 1–2 档）而肤色曝光准确。

光
背景独立打灯

至少两盏灯专门打亮白背景（比主体亮 1–2 档），主体再用大柔光箱正面偏上补光，光比极小、几乎无影。

测
按脸测光、宁过勿欠

点测面部中间调，直方图靠右但不碰墙；白背景略过曝是正常的，欠曝会发灰脏。

搭
服装浅色系呼应

白、米、浅粉等浅色服装与高调氛围统一；深色服装会破坏整体明亮感（除非刻意对比）。

+1 ~ +2 EV白背景过曝光比 ≤ 1:2白平衡偏冷更通透
完整拍摄方案 · 器材 / 场景 / 灯光 / 人物 / 参数 / 后期
器材全画幅 + 24–70 f/2.8 或 85mm；两支 120cm 八角箱专打背景；一支带柔光布的大面积主灯；白色大反光板；白色无缝背景纸。
场景全白影棚：白背景纸从天到地包住并拉平褶皱，或直接白墙白地；移走画面内一切深色物体。
灯光两支灯分别左右打背景，测光比面部亮 1.5–2 档——背景先过曝才能纯白；主灯正面偏上透过柔光布均匀铺人物；白色反光板在下方向上补下巴阴影；检查人物影子不打在背景上（灯位抬高、人物离背景）。
人物与引导全身白色着装（白衬衫/白裙/米色针织），妆容清透水光、唇色是唯一色彩点；头发细致去碎发（白色背景碎发全暴露，发胶+吸尘器处理）；表情轻松微笑。
相机参数ISO 100｜f/2.8–4｜对面部测光，直方图右侧贴边但不碰壁｜曝光 +0.7–1EV｜背景读数 250–255。
后期处理白平衡必须准确偏灰即翻；高光拉回恢复细节；背景色阶推向纯白；HSL 橙色明度+10 提亮肤色；边缘锐化保留不糊。
03
LOW-KEY

低调暗调风格神秘 · 力量感 · 明暗对照

大面积黑、小面积光的「明暗对照法（Chiaroscuro）」。常用侧逆光勾勒轮廓，让脸的大部分沉入黑暗，只留一只眼睛或一道腮线发光。适合男性肖像、运动、音乐主题。

光
控光比切光更甚于加光

用束光筒、四门格、旗板把光「裁」成需要的一条/一片；灯离人物远则光更硬更窄。背景保持全黑（人物远离背景）。

测
只对亮部测光

点测受光的脸侧，让暗部自然掉到黑场；后期压黑时保留暗部一档细节，避免死黑一团。

边
发丝轮廓光是灵魂

一盏硬光从侧后方 135° 打头发与肩部边缘，把主体从黑背景里「剥离」出来。

点测亮部光比 1:8+黑色吸光布背景后期压黑留细节
完整拍摄方案 · 器材 / 场景 / 灯光 / 人物 / 参数 / 后期
器材机身 + 85/135mm f/1.8–2.8；单灯束光筒/聚光筒（barn door）或加蜂巢的条形箱；黑色旗板两块；黑色哑光背景。
场景全暗影棚：黑背景在人物身后 ≥2m；遮光处理——拉窗帘、黑色吸光布盖住反光物，先关灯测环境光为 0。
灯光只留一盏加蜂巢条灯/束光筒，从人物侧后方 135–160° 掠过，只照亮一侧脸颊边缘、下颌线与肩部轮廓，正面完全沉入黑；两侧黑旗夹住防止余光溢出照亮背景；光比 >1:8。对受光面最亮处点测。
人物与引导深色服装融入背景（黑高领/深色西装），只露出轮廓镶边；表情克制、眼神投向画面暗处；身体背光的侧对镜头，让脸只有一条光带。发型收整齐——边缘光下碎发全部可见。
相机参数ISO 100–200｜f/2.8–4｜点测受光亮面、-0 至 -1/3EV｜白平衡微冷 5000K 让黑区偏冷蓝。
后期处理黑场压实（Level 黑点上调至背景纯黑）；只保留高光边缘层次；肤色暖/环境冷的分离色调；暗部降噪 -10；检查高光无溢出。
04
BLACK & WHITE

黑白高反差风格纹理 · 情绪 · 岁月感

抽掉色彩后，光影、线条与皮肤纹理成为主角。特别适合饱经风霜的面孔（老人、劳动者）和强调肌肉线条的形体。侧光 / 硬光最能「雕刻」皱纹与质感。

选
先判断「这张脸值不值得黑白」

黑白适合有故事的面孔、强烈光影或极简构图；皮肤瑕疵多、依赖色彩氛围的题材反而不适合。

光
侧向硬光强化纹理

光越侧、越硬，皱纹与毛孔越突出；想柔和一点就加柔光箱但仍保持侧位。

后
用黑白转换而非直接去色

调整红/橙通道提亮肤色，加曲线做深黑高白；局部加深减淡（Dodge & Burn）重塑光的走向。

拍摄时 RAW+黑白预览直方图两端留空间对比曲线 S 形
完整拍摄方案 · 器材 / 场景 / 灯光 / 人物 / 参数 / 后期
器材高像素机身（A7R/Z7）+ 50/85mm 定焦；标准罩裸灯（硬光核心）或保丽龙反光板挖孔灯；银色反光板；偏振镜控反光。
场景灰色无缝纸，或带粗糙纹理的现场（砖墙/旧木门/混凝土）。模特优选有故事的面孔——皱纹、伤疤、骨相分明都成为素材。
灯光裸灯/标准罩硬侧光在正侧 90°、略高于头 45°：皮肤纹理、胡茬、皱纹被浮雕式拉出，阴影边界清晰硬朗；对面银色反光板补 1/4 光或干脆不补保高反差；这是唯一光源。
人物与引导着装极简深色无图案（防干扰）；表情沉稳、眼神直视镜头有对抗感；妆容必须哑光；让模特做微表情（抿嘴/皱眉）找到最有力的一帧连拍。
相机参数ISO 100｜f/5.6–8 保细节｜对高光侧脸部点测 0｜RAW + 机内单色预览辅助判断。
后期处理黑白转换：通道混合器红色 +20 提亮肤色、蓝色 -30 加深阴影与背景；S 形曲线拉反差；清晰度/结构 +20；颗粒 +15 模仿银盐；输出时检查白点不过。
05
NATURAL / WINDOW LIGHT

窗边自然光风格居家 · 咖啡馆 · 柔和过渡

不买灯也能出大片：一扇大窗就是巨型柔光箱。侧对窗户时光比自然、立体感强，背景随距离迅速暗下去，形成天然的暗调渐变，情绪安静内敛。

位
脸朝向窗、离窗 1–2m

大阴天或纱帘后的散射光最柔；想让暗部有细节就靠近窗，想要强烈明暗就远离窗（平方反比定律）。

补
白色墙面/反光板就是免费辅灯

暗侧朝向白色家具即可自然补光；需要更可控就用银色反光板距人物 1m 斜反射。

镜
开大光圈，ISO 放宽

f/1.4–2.8，ISO 400–1600 无所谓——干净暗部比噪点重要，快门不低于安全速度即可大胆手持。

50/85mm f/1.4–2侧窗 90° 光位WB 手动 5000K 统一氛围
完整拍摄方案 · 器材 / 场景 / 灯光 / 人物 / 参数 / 后期
器材机身 + 50/85mm f/1.4–1.8 大光圈定焦；不闪光；白色反光板一块；可用纱帘调光。
场景北向大窗的房间（全年光柔且稳定），选上午 9–11 点 / 下午 3–5 点无直射阳光时段；关掉室内灯防色温混杂；背景为窗景或简洁墙面。
灯光窗户是唯一光源——窗即巨型柔光箱：脸颊离窗近则光柔亮、远则收暗，靠距离控制光比而不是灯具；用 45° 侧前或正侧光造型立体；阴影侧用白板补光（近=亮远=暗）或放弃填充保留情绪；纱帘做半透可再软化一档。
人物与引导家居服/针织/衬衫，妆容素颜感；坐姿侧对窗、或背对窗回眸；手捧咖啡杯/书让姿态松弛；视线看窗外或越过镜头，不直视。
相机参数ISO 400–800｜f/1.4–2.8 虚化背景｜对面部点测 +2/3EV（皮肤通透）｜白平衡偏冷一点保窗光干净。
后期处理阴影适度提亮但保留窗外→窗内的衰减过渡；肤色暖 vs 环境冷的微对撞；轻微柔化高光；白平衡统一不偏黄。
06
BACKLIT · GOLDEN HOUR

逆光 / 金色时刻风格发丝光 · 光斑 · 浪漫氛围

日出后或日落前一小时，低角度的太阳成为天然轮廓灯：发丝镀金、空气透光、光斑唯美。逆光是「浪漫感」的最强来源，也是氛围写真首选。

时
只拍黄金一小时

太阳越低越金黄越柔；正午顶光只会睁不开眼+阴阳脸。提前 40 分钟到场踩点机位与太阳方位。

测
对脸测光、让太阳过曝

逆光下点测面部（或让模特先面向太阳再转回），欠曝画面氛围就没了；可用反光板/机顶闪 +1EV 补脸。

炫
巧用眩光与树影遮挡

让太阳藏在树缝、发丝后呈星芒；摘掉遮光罩（注意灼伤传感器风险）或用长焦贴近主体制造光晕。

135mm f/2 压缩太阳WB 6500K+ 强化暖调+0.5~1 EV
完整拍摄方案 · 器材 / 场景 / 灯光 / 人物 / 参数 / 后期
器材机身 + 85/135mm f/1.8–2.8；金/银反光板（必备）；或机顶闪光灯补光档；遮光罩必装。
场景开阔草地/田野/湖边，镜头正对落日，选太阳刚贴地平线的 20–40 分钟；机位压低让太阳恰好落在人物头侧。
灯光太阳在人物正后逆光：发丝透光成金圈、身体镶边；金色反光板在人物前下方 45° 把暖光反弹进脸部（或闪光 -1EV 补光）；对脸部测光，让太阳与天空自然过曝；太阳藏到人头后侧 15° 减少眩光雾，斜插遮光罩压杂光。
人物与引导白色/鹅黄飘逸长裙（透光），长发出丝光效果最佳；引导慢速转身/走路回眸让发丝飞扬；道具蒲公英/仙女棒/透明伞出前景光斑。
相机参数ISO 100｜f/2–2.8（太阳出圆光斑）｜1/400s｜对脸 +2/3–1EV｜白平衡 6000K+ 保暖。
后期处理高光加金橙、天空向青；镜头光晕处加暖不修掉；肤色橙黄方向；暗部加青保胶片味；整体向琥珀色调。

07
JAPANESE AIRY FILM

日系空气感小清新过曝 · 低反差 · 胶片色

「空气感」= 明亮 + 轻透 + 低饱和。高光轻微溢出、阴影提亮发灰、色彩清淡干净、留白多、抓拍自然笑容。像夏天的一杯苏打水。

曝
过曝 +1 档是风格不是失误

让高光「雾化」溢出：直方图贴右墙但不切；配合浅色服装与晴天顺光/散射光环境。

色
低饱和 + 偏青绿的胶片色

后期降对比、提阴影、绿/青向里加一点白；模拟 Portra / 富士 C200 的淡雅色调，避免浓郁撞色。

拍
生活流抓拍 > 摆拍

35mm 视角、日常道具（伞、冰饮、自行车），引导模特「做事」而非看镜头，构图多留白、允许不居中。

35mm f/2+0.7~1.3 EV提阴影 -对比颗粒感轻度叠加
完整拍摄方案 · 器材 / 场景 / 灯光 / 人物 / 参数 / 后期
器材机身 + 35/50mm f/1.8–2.8（或胶片+Portra/400H）；一块白色反光板当填充；浅色衣服本身就是反光板。
场景日系街区/便利店门口/斑马线/天台/河堤，白天阴天或开阔阴影下最佳；环境选浅色调（白墙、淡蓝天空、浅色招牌）。

DOCUMENTARY
